# Jejak Rimba — Sewa Alat Camping & Mendaki

**Edgard Mahardika / 10 XI RPL A**

Platform sewa alat camping dan mendaki di Malang Raya (Malang, Batu, Lawang).  
Dibangun dengan Next.js 16, TypeScript, Tailwind v4, Framer Motion, dan Supabase.

## Fitur

- Katalog alat camping dengan filter kategori & lokasi
- Halaman detail alat (stok, harga, lokasi, kondisi, dll)
- Booking flow: pilih tanggal → isi data → konfirmasi
- Autentikasi user (login/register)
- Dashboard vendor
- Responsive mobile-first + desktop premium

## Tech Stack

- **Framework:** Next.js 16 (Turbopack)
- **Bahasa:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animasi:** Framer Motion
- **Ikon:** Lucide React
- **Font:** Archivo + JetBrains Mono
- **Database:** Supabase (PostgreSQL)
- **Deploy:** Vercel

## Cara Menjalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
